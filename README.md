Topics Explored

Computer Hardware & IPOS: Input-Processing-Output-Storage workflows, hardware vs. software classification, and everyday embedded systems.

Command-Line Operations: Navigating directories, managing files, command flags (-l, -a, -h), pipes ("|"), and Homebrew package management.

Operating Systems: macOS environment inspection, process identifiers (PIDs), absolute vs. relative paths, file permissions (`rwx`), and core OS responsibilities.

Program Execution: Running Python 3 scripts and comparing compilers vs. interpreters.

Data Representation: Manual decimal/binary/hexadecimal conversions, ASCII/UTF-8 encoding, and interactive Python conversion utilities.

Version Control: Staging, committing, branching (`update-about`), and opening a Pull Request on GitHub.

Networking: LAN/MAN/WAN architectures, DNS resolution, routers, protocols, packet switching, and client-server web communication.
